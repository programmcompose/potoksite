    100 фишек продюсера #

    Большая подборка из 100 продакшн-приёмов: от атмосферных слоёв и глитч-вокала до переходов, ризеров и «сломанных» эффектов. Каждая фишка — пошаговый рецепт: что сделать, какие параметры крутить и как смешать результат с оригиналом.

    Источник

    Материал основан на видео-гайде morsbeats_ — «f**k it, steal these 100 producer effects». Рецепты описаны для Ableton Live; в любой другой DAW используйте аналоги (bounce in place, resample, slice to MIDI — есть везде).

    Как читать эту статью #

    • Фишки разбиты на 9 категорий: мелодии, бас, вокал, драмка, delay/reverb, глитчи, переходы, сайдчейн/гейты и сэмплирование.
    • Номера 1–100 сквозные — можно ссылаться на них как на «карточки».
    • Значения параметров (Гц, %, доли нот) — стартовые: подстраивайте под свой трек по слуху.

    Мелодии и синты #

    1. Halftime — «полувремя» #

    Глубокий замедленный слой под основной мелодией.

    1. Дублируй мелодию.
    2. Растяни копию в 2 раза по длине (warp).
    3. Сдвинь питч на −12 полутонов (−октава).
    4. EQ: срежь низы ~100–150 Гц — питч-даун добавляет мутного суба.
    5. Смешай с оригиналом по вкусу.

    2. Haunting Melodies — «мрачная мелодия» #

    Призрачный слой, который «догоняет» основную линию.

    1. Дублируй мелодию и реверсни копию.
    2. Реверб: decay ~8 сек, wet 100%.
    3. Freeze & Flatten — рендерни дорожку в аудио.
    4. Чуть растяни результат, затем снова реверсни.
    5. Выровняй по оригиналу, сдвинь питч на −12 полутонов.
    6. EQ: band-pass 200 Гц – 3 кГц.

    3. Ambitextures — эмбиент-текстура #

    Фоновая текстура из простого аккорда.

    1. Возьми простой аккорд (синт/пэд).
    2. Реверб: decay ~60 сек, wet 100%.
    3. Freeze & Flatten.
    4. Обрежь начало (первый удар аккорда) и тихие хвосты.
    5. EQ: band-pass ~450 Гц – 1,5 кГц.

    4. Layers — слой из реверс-нот #

    Воздушный слой над простой мелодией.

    1. Возьми простую мелодию (по ноте на долю).
    2. Дублируй и реверсни каждую ноту по отдельности (каждую четверть).
    3. Добавь всем нотам fade-in.
    4. Consolidate — склей всё в один клип.
    5. Питч +12 полутонов, растяни в 2 раза.

    5. RevCrush — реверс + биткрашер #

    Глитч-слои только на «перевернутых» участках мелодии.

    1. Дублируй мелодию и реверсни случайные куски копии.
    2. Bitcrusher (Redux): wet ~50%, rate ~11 кГц.
    3. Автоматизация: включай крашер только на реверс-участках.
    4. Маленькие фейды, чтобы убрать клики.

    6. Simples — отложенный эхо-слой #

    «Прыгучий» слой с опозданием в такт.

    1. Дублируй мелодию.
    2. Питч +12 полутонов (в Ableton удобно через warp Complex Pro + formant).
    3. Сдвинь копию назад на один такт.

    7. Talking Synth — «говорящий» синт #

    Синт, который «поёт» вместе с вокалом.

    1. Синт-дорожка + дорожка вокала рядом.
    2. Auto Filter на синте: сайдчейн от вокала (gain сайдчейна подними по вкусу).
    3. Если в плагине есть режим гласных/VOX — включи его; питч −36 полутонов, morph 100%, envelope 100%.

    8. LFO Synth — дышащий фильтр #

    Эволюционирующий фильтрованный синт.

    1. EQ: low-pass фильтр.
    2. LFO → маппинг на частоту фильтра, диапазон 0–100, sync rate = четверть, smoothing 100%.
    3. Автоматизация по времени: depth от 0 до 100 и offset от −50 до +100.

    9. 1234 — трип-паттерн из плка #

    Триповая нарезка из короткого плка.

    1. Короткий плк (восьмая/четверть).
    2. Дубликат с ревербом: decay максимум, wet 100% → bounce in place.
    3. Обрежь атаку и хвост у дубликата, убавь громкость.
    4. Resample обе дорожки вместе на новую аудио-дорожку.
    5. Реверсни клип в каждом месте удара ноты.
    6. Копируй случайные такты и вставляй в случайные места — собирай свой паттерн.

    10. Vibe — двойной реверс-делэй #

    Два «размытых» слоя с разными ритмами.

    1. Дублируй мелодию дважды, оба дубликата — MIDI-reverse.
    2. Первый: delay = четверть, feedback 50%, wet 100%. Второй: delay = триплет (3/16), те же настройки.
    3. Freeze & Flatten обе дорожки.
    4. Разнеси по времени, затем снова реверсни и выровняй с оригиналом.
    5. На обоих слоях band-pass EQ ~100 Гц – 3 кГц.

    11. Melody Trip — эмбиент-мелодия #

    Мечтательный слой из обычной мелодии.

    1. High-pass ~1,5 кГц → chorus 100% → реверб decay ~14 сек, wet 100%.
    2. Bounce in place.
    3. Растяни в 2 раза, обрежь хвост.
    4. Low-pass ~2 кГц.

    12. EZ Songstarter — трек из одной мелодии #

    Контрмелодия и баслайн из одного фразирования.

    • Контрмелодия: дубликат → питч +12 → reverse → сдвиг на восьмую.
    • Баслайн: дубликат → смени синт на басовый → питч −12 → legato → удаляй случайные ноты, пока не понравится.

    Одна мелодия — и у тебя уже каркас трека.

    13. Disenchanted — эфирный слой #

    Эфирное «облако» вокруг мелодии.

    1. Дублируй мелодию.
    2. Delay: полнота (half note), feedback 95%, wet 100%.
    3. Band-pass фильтр ~1 кГц (wet 100%).
    4. Реверб: decay ~4 сек, wet 70%.
    5. Смешай с оригиналом до нужного «сладкого пятна».

    14. Tails — инструмент из хвостов реверба #

    Играбельная MIDI-мелодия, состоящая из хвостов реверба вокала.

    1. Вырежи кусок вокала на новую дорожку.
    2. Реверб: decay ~14 сек, wet 100% → freeze & flatten.
    3. Загрузи результат в самплер (Simpler).
    4. Обрежь атаку, чтобы убрать клики; подстрой attack.
    5. Добавь второй реверб: decay ~4 сек, wet 50%.
    6. Играй мелодии на клавиатуре — звучит как «поющие хвосты».

    15. ONA — атмосфера из одной ноты #

    Пэд-атмосфера из одиночной ноты (например, колокольчика).

    1. Несколько питч-шифтеров: −12 (wet ~37%), −5 (~31%), −3 (~34%) — подбирай интервалы так, чтобы получались тона аккорда.
    2. Реверб: decay ~18 сек, wet 100%.

    16. Counter Melody — контрмелодия одним кликом #

    Новая мелодия из старой без написания нот.

    1. Дублируй MIDI-мелодию.
    2. MIDI Recombobulator: включи shuffle → жми Transform (ноты переставляются).
    3. Выдели всё и сдвинь питч +октава.
    4. Жми Transform снова — получаешь новые вариации бесконечно.

    17. Melody Repeater — повторяющаяся мелодия #

    Ритмично повторяющийся слой поверх мелодии (Beat Repeat).

    • Interval: четверть, chance: 100%, gate grid: 1/16.
    • Pitch shift по вкусу (например, −12), громкость +6 дБ.
    • Добавь фильтр по вкусу — и слой «дышит» ритмом.

    Бас #

    18. Bass Booster — параллельная сатурация низов #

    Дополнительный вес и гармоникам в низах баса.

    1. Новая return/bus-дорожка: EQ low-pass ~100 Гц.
    2. Сатуратор (Decapitator или любой): drive максимум, wet максимум — «boosted» настройка.
    3. Шледи бас на эту шину и смешивай по вкусу.

    19. Big Bass — «ныряющий» бас #

    Каждая нота баса «ныряет» вниз октавой и бьёт жёстче.

    1. На каждой ноте: envelope clip transposition от 0 до −12 полутонов с крутой кривой (вне Ableton — питч-шифтер).
    2. Агрессивная сатурация: boost низов, без средних, чуть верхов — «в лицо».

    20. Kick → 808 — кик как бас #

    Свой 808 из обычного кика за два плагина.

    1. Drum Buss: boom максимум, output убавь (boom добавляет громкость).
    2. Сатуратор (Decapitator): wet максимум, настройки под свой звук.
    3. По желанию — freeze & flatten и нарезка в MIDI.

    21. Pad Kick — пэд из кика #

    Four-on-the-floor кик превращается в мелодичный пэд.

    1. Кики группами по четыре: меняй питч каждой (например, 0 / −4 / +5 / −8 полутонов).
    2. Convolution-реверб: загрузи пэд как импульсный ответ, attack ~500 мс, decay ~20 сек, wet 100%.
    3. EQ: high-pass ~800–1 кГц.

    22. Low & Slow — тёмное замедление #

    Тёмный «замедленный» слой для аутро и брейкдаунов.

    1. Resample кусок трека на новую дорожку.
    2. Растяни в 2 раза (warp Complex, чтобы остался мягким).
    3. Питч-шифтер: −12 полутонов, wet 100%.

    Вокал #

    23. Reverse Stutters — реверс-стаггеры #

    Стаггерный вокальный слой с «обратным» хвостом перед словом.

    1. Дублируй вокал → reverse → реверб decay ~1,2 сек, wet 100%.
    2. Freeze & flatten → снова reverse → выровняй с оригиналом (хвост теперь играет перед словом).
    3. Stutter-плагин: sine wave, amount ~60%, rate 1/48.
    4. Сайдчейн от кика и снейра — для «отскока».
    5. По вкусу — EQ-чистка вокала.

    24. Glitched Vocals — глитч-вокал #

    Триповое «дыхание» из обычного вокала.

    1. Выдели вокал и растяни в 2 раза.
    2. Consolidate и верни исходную длину (÷2 дважды).
    3. Warp mode: Beats.
    4. Reverse. Готово.

    25. Delayed Vox — фоновые эхо-слои вокала #

    «Гармонические» эха на фоне основного вокала.

    1. Скопируй нужные куски вокала на новую дорожку.
    2. Delay: четверть, feedback 50%, wet 100% (время зависит от BPM).
    3. Реверб: decay ~6,5 сек, wet ~32%.
    4. Band-pass EQ 350 Гц – 3 кГц.
    5. Разные копии сдвинь по питчу: +7 / +2 / 0 полутонов.

    26. Elegant — элегантный ризер из слова #

    Ризер, который «поёт» первым словом фразы.

    1. Скопируй первое слово вокала на новую дорожку и вручную «задерживай» его до момента входа вокала.
    2. Consolidate в один клип + fade-in.
    3. Formant-шифтер (Little AlterBoy): автоматизация formant от 0 до −12 на всю фразу.
    4. Реверб decay ~5–6 сек: автоматизация wet от 0% до ~65%.

    27. Reverse Reverb — реверс-реверб #

    Классический эффект: хвост реверба «идёт» перед словом.

    1. Первое слоги слова → новая дорожка → reverse.
    2. Большой реверб: decay ~7 сек, wet 100%.
    3. Freeze & flatten → снова reverse → выровняй так, чтобы хвост заканчивался ровно в начале слова.
    4. Маленький fade-out на конце.

    28. Bouncy Stutters — прыгучие стаггеры #

    Ритмичный «прыгающий» слой из вокала.

    1. Stutter-плагин: wet 100%, rate = восьмой триплет (3/16).
    2. Дублируй дорожку; на втором дубликате rate = шестнадцатая + реверб перед стаггером (decay ~5 сек, wet 100%).
    3. Смешай обе дорожки по громкости.

    29. Whispers — шёпот #

    Жуткий шепчущий слой под вокалом.

    1. Дублируй вокал → reverse.
    2. Вокодер: 40 bands, range 18–80; уровень +несколько дБ; release минимум, attack максимум, depth чуть выше.
    3. Freeze & flatten → reverse → выровняй с оригиналом.

    30. Haunting Pad — пэд из вокала #

    Мрачный фоновый пэд из растянутого вокала.

    1. Дублируй вокал и растяни в 2 раза.
    2. Reverse; выбери случайный кусок, который нравится, и зацикли его на весь трек.
    3. Реверб: decay ~2,5–3 сек, wet 100% + band-pass 225 Гц – 2,5 кГц.
    4. Убавь громкость по вкусу.

    31. Demon Time — «демонический» подвокал #

    Тёмный грит-слой под основным вокалом (идеально для drill).

    1. Дублируй основной вокал → питч −5 полутонов (warp Complex).
    2. Сатурация (Decapitator): drive ~7, mid-tone, wet ~60%.
    3. Лёгкий сайдчейн от оригинального вокала — чтобы слой не перекрывал лид.

    32. Grainy Vocals — зернистый вокал #

    Движущийся гранулярный эффект на вокале.

    1. Дублируй вокал (warp): сожми длину ÷2 трижды → consolidate → растяни обратно ×2 трижды.
    2. Warp mode: Textures: grain size максимум, flux минимум.
    3. Реверб: decay ~1,2 сек, wet ~70%.
    4. Автоматизация grain size «треугольником» каждые пару тактов — зерно «едет».

    33. Pretty Vocal — «красивый» вокал #

    Нежная обработанная копия вокала для фона.

    1. Скопируй нужные куски на новую дорожку.
    2. Little AlterBoy: питч −4 полутона.
    3. Реверб: decay ~6 сек, wet ~75%.
    4. Chorus (хороший бесплатный плагин): wet 50%, полная стерео-ширина.
    5. Delay: полнота (half note), feedback 33%, wet 33%.
    6. EQ: мягкий band-pass 300 Гц – 9 кГц.

    34. Vocal Rewind — «перемотка» вокала #

    Глитч-эффект «назад перемотки» из нарезанного вокала.

    1. Slice вокала в новую MIDI-дорожку (half note).
    2. Сыграй свой чоп-паттерн на клавиатуре.
    3. Дублируй результат → freeze & flatten.
    4. На аудио-копии реверсни случайные ноты/клипы.

    35. Vocal Pad — пэд из фразы вокала #

    Красивый атмосферный слой из куска вокала.

    1. Вырежи кусок вокала на новую дорожку.
    2. Огромный реверб: decay ~60 сек (максимально большой), wet 100% → freeze & flatten, убавь громкость.
    3. Обрежь участок, где фраза ещё слышна как слова.
    4. Дублируй часть и reverse — для «потока».
    5. Band-pass EQ 200 Гц – 1,1 кГц, смешай в трек.

    36. Delay Pitch — мост между секциями #

    Плавный переход между частями трека с разной тональностью.

    1. Последнее слово вокала → новая дорожка + fade-in на старте.
    2. Реверб: decay ~7 сек, wet 100%; delay: четверть, feedback 95%, wet 50%.
    3. Питч-шифтер: автоматизация mix до 100% (начни со второй половины фразы) и питча от 0 до +2 полутонов — под тональность следующей секции.
    4. EQ: high-pass ~170 Гц + low-cut ~3 кГц.

    37. Telephone — «телефонный» звук #

    Звук «через телефон» для вокала и мелодий.

    1. EQ: пресет Telephone Vocal (Ableton EQ Eight; в других DAW — ручные настройки по частотам).
    2. Bitcrusher: rate 40 кГц, wet 100%; крути bits вниз, пока не появится «шум телефона».

    38. Radio — «радио» #

    Звук старого радиоприёмника.

    1. Телефонный EQ (как в фишке 37).
    2. Vinyl-треск/дисторшн: crackle ~40% — ничего лишнего, только характер.

    39. Tape Stop — «остановка плёнки» #

    Классический tape stop на слове.

    1. Питч-шифтер на вокале, wet 100%.
    2. Автоматизация питча от 0 до −24 полутонов прямо на слове — начинай сразу после начала слова, чтобы эффект был агрессивным.
    3. Дублируй автоматизацию на другие слова по вкусу.

    40. Trip — трип-вокал #

    Триповый «дышащий» слой из вокала.

    1. Warp вокала → растяни ×2 → consolidate и верни ÷2 дважды.
    2. Warp mode: Beats.
    3. Reverse.

    41. Vocal Repeat — бит-повтор вокала #

    Ритмичные повторы фразы (Beat Repeat).

    • Interval: четверть, chance: 100%, gate grid: 1/16.
    • Variation klzzw:0172, громкость +3 дБ.
    • Добавь фильтр по вкусу — и вокал «отбивает» ритм.

    42. Sample Offset — «сдвиг» сэмпла #

    Странный «сломанный» вокал через сдвиг точки старта сэмпла.

    1. В аудио-редакторе крути sample offset клипа вокала — слушай и находи интересные фрагменты (звук как бы «подменяется»).
    2. Пройдись по всему клипу, делая сдвиги в разных местах.
    3. Затем редактируй transposition: изредка опускай на −5 полутонов.

    Эффект требует внимательного прослушивания — но результат очень характерный.

    Драмка #

    43. Snare Slaps — «хлесткий» снейр #

    Дополнительная «щёлка» перед каждым снейром без смены звука.

    1. Зумни на снейр и вырежи маленький фрагмент перед ударом.
    2. Очень короткий fade-in на этом фрагменте.
    3. Расставь такие фрагменты перед всеми снейрами в паттерне.

    44. Hat Roll — ролл из хэтов #

    Плавный «разгон» хэтов для переходов.

    1. Копируй хэт вручную на 1/32–1/64 (зависит от BPM).
    2. Consolidate в один клип + fade-in.
    3. Low-pass ~8 кГц — чтобы отодвинуть назад.
    4. Реверб: decay ~2,7 сек, wet 25%.
    5. Delay: шестнадцатая, feedback 20%, wet 20%.

    45. Alien Drums — «чужие» барабаны #

    Жуткие «инопланетные» драмы из обычного лупа.

    1. Драм-луп → реверсни случайные маленькие фрагменты (выбирай на слух).
    2. Flanger/phaser: time ~13 мс, amount минимум, feedback ~80%, wet ~25%.
    3. Крути настройки — каждая даёт свой вайб.

    46. Drum Extraction — извлечение драм из лупа #

    Собери свой паттерн из звуков чужого драм-лупа.

    1. Драм-луп → slice в новую MIDI-дорожку по transient.
    2. Примени драм-пресет (Ableton предложит при нарезке) — каждый хит становится отдельной нотой.
    3. Удали оригинал и собирай свой паттерн из этих звуков.

    47. Ping Pong Ball — «пинг-понг» из one-shot #

    Открывающийся «прыгающий» эффект из одиночного сэмпла.

    1. One-shot в Drum Sampler: attack ~750 мс, decay ~1 сек, mode Gate, effect Loop.
    2. Автоматизация: filter frequency от 250 Гц до открытого (22 кГц) + длина loop-эффекта от 10 мс до 365 мс.
    3. Реверб: decay ~8 сек, wet 30%.
    4. На второй копии — инвертируй всю автоматизацию.

    Delay и Reverb #

    48. Reverse Delays — реверс-делэй #

    Делэй, который «бежит» перед фразой.

    1. Реверсни вокал/фразу.
    2. Delay: wet 100%, feedback ~40%, время = полнота (в Ableton — восьмая).
    3. Freeze & flatten → reverse обратно и выровняй с оригиналом.

    49. Slappy Chorus — «хлесткий» хорус-шину #

    Готовая шина для отправки вокала/мелодии.

    1. Return track: delay = восьмая, feedback 50%, wet 100%.
    2. Сатурация (Decapitator): drive выше, более тёмный тон, wet максимум — «грит».
    3. Chorus: полная стерео-ширина, wet ~50%.
    4. Band-pass EQ 150 Гц – 3,5 кГц.
    5. Шли вокал/мелодию на шину.

    50. Grainy — гранулярная шина #

    Широкая «скользящая» текстура для отправки любого звука.

    1. Return track: grain delay (гранулярный): wet 100%, rate ~1 Гц, pitch +12 полутонов.
    2. Реверб: decay ~3,5 сек, wet 100% — звук становится огромным и широким.
    3. Low-pass ~1,3 кГц — отодвигает назад.

    51. Aesthetic Slaps — «эстетичные» хлопки #

    Быстрый slap-слой с дисторшном для вокала и мелодий.

    1. Return track: delay 20 мс, feedback 0%, wet 100% (чистый короткий сдвиг).
    2. Жёсткий дисторшн — для «искажённого» вайба.
    3. Реверб: decay ~1 сек, wet 100% — «комнатность».
    4. Band-pass EQ 400 Гц – 2,5 кГц — чтобы не давило.

    52. Reverb Swells — «дыхание» реверба #

    Реверб, который плавно набухает и спадает.

    1. Реверб с большим decay (~16 сек) на дорожке.
    2. Автоматизация wet: рисуй «набухающие» паттерны (вверх-вниз, разные формы).
    3. Плавные кривые — чтобы не было кликов.

    53. Slow Stutters — замедляющиеся стаггеры #

    Стаггер, который «замедляется и открывается».

    1. Auto Filter: low-pass 24 dB, LFO amount ~10%.
    2. Автоматизация частоты фильтра между 205 Гц и 20 кГц — «открытие» звука.
    3. Автоматизация rate LFO: от 30-секундной ноты до четверти — стаггер замедляется.
    4. Wet 100%.

    54. Double Delays — двойной делэй #

    Два делэя с разными ритмами одновременно.

    1. Return A: delay = четверть, feedback 30%, wet 100%.
    2. Return B: delay = триплет (3/16), feedback 30%, wet 100%.
    3. Шли аудио на обе шины и смешивай по вкусу; меняй времена (например, на «пятую») для новых паттернов.

    55. Delay Swells — «дыхание» делэя #

    Аналог Reverb Swells, но для делэя.

    1. Быстрый slap-делэй: feedback ~95%.
    2. Автоматизация wet по плавным кривым там, где хочешь появления/исчезновения эха.

    56. Ghostly — «призрачный» слой #

    Тёмный эмбиент-слой под вокалом или мелодией.

    1. Return track: питч-шифтер −12 полутонов, wet 100%.
    2. Реверб: decay ~5,5 сек, wet 100%.
    3. Auto pan: sine wave, amount ~60%, rate ~22 Гц — плавное движение влево-вправо (крути под свой трек).

    57. Blur — «размытие» #

    «Скользящее» размытое эхо.

    1. Return track: EQ band-pass ~1,5 кГц (изолируем верхи средних).
    2. Реверб: decay ~4 сек, wet 100%.
    3. Питч-шифтер +12 полутонов, wet 50%.
    4. Фиксированный delay 350 мс — «скольжение».

    58. Split Delays — разделённый делэй #

    Низы и верхи «бегут» с разными задержками.

    1. Return A: low-pass ~1 кГц + delay четверть, feedback 32%, wet 100%.
    2. Return B: high-pass от 1 кГц (спектр делится без дыр) + delay полнота/восьмая, feedback 32%, wet 100%.
    3. Шли аудио на обе шины; точку разделения EQ подбирай под звук.

    59. Flanger Delays — фленжер-делэй #

    Красивое «мерцающее» эхо.

    1. Return track: high-pass ~350 Гц.
    2. Delay: полнота/восьмая, feedback 35%, wet 100%.
    3. Flanger: mix 50% (настройки под свой вкус).
    4. Реверб: decay ~2,5 сек, wet 40% — атмосфера.

    60. Open Stutter — «открывающийся» стаггер #

    Стаггер, который замедляется и растворяется в полном звуке.

    1. EQ low-pass: автоматизация от ~600 Гц до полностью открытого там, где нужен эффект.
    2. Stutter (sine wave): amount от 100% до ~70% + rate от 1/64 до четверти.

    61. Nice Delay — «телефонный» делэй #

    Slap-делэй с телефонным характером.

    1. Return track: delay = восьмая, wet 100%, feedback ~25%.
    2. Сатурация (Decapitator): wet ~75%, drive по середине.
    3. Band-pass EQ 500 Гц – 3,3 кГц — «телефонная» зона.

    Glitch и стилизация #

    62. Distortion Fun — агрессивный дисторшн #

    Жёсткий «раздавленный» звук с ритмичным эхом.

    1. Дублируй дорожку.
    2. Delay: триплет (3/16), feedback 0%, wet ~35%.
    3. Сильный дисторшн/сатурация — «на максимум».
    4. Убавь громкость — дисторшн сильно прибавляет уровень.

    63. Video Game — «видеоигра» #

    8-bit ретро-звук из любого звука.

    1. Bitcrusher: rate ~4–5 кГц, wet ~40% — «разбитый» 8-bit характер.
    2. Питч-шифтер −12 полутонов с очень малым wet (~12%) — едва слышный суб-слой.

    64. Broken Game — «сломанная игра» #

    Эффект «упавшего» игрового звука — отлично для интро/аутро YouTube.

    1. Аудио-клип (warp Complex/Complex Pro): автоматизация transposition от 0 до −12 на протяжении двух тактов.
    2. Bitcrusher: rate от ~11 кГц до ~117 Гц, 16 bits, wet 100% — тоже автоматизируй.
    3. Low-pass фильтр: от открытого до ~250 Гц.

    65. Glitches — глитч-стек #

    Полный «глитч»-набор на дубликате дорожки.

    1. Реверб: decay ~2 сек, wet 50%; delay: четверть, feedback 50%, wet 50%.
    2. Auto pan в режиме random: rate 1/16, amount ~70% — «триповые» прыжки громкости.
    3. Overdrive/сатурация: drive klzzh:0279, wet ~24% — агрессия.
    4. LFO с jitter управляет сразу high-pass и low-pass фильтрами (sine, depth 60%, rate = один такт) — «дрожание» спектра.
    5. Смешай глитч-слой с оригиналом.

    66. Club Toilet — «туалет в клубе» #

    Музыка «через стену клуба».

    1. На мастере: low-pass ~800 Гц.
    2. Реверб: decay ~3,5 сек, wet ~38%.

    67. Specter — «спектральный призрак» #

    Ультра-разрешённый «замороженный» эффект на вокале.

    1. Вокал на новую дорожку → питч-шифтер +12 полутонов, mix ~50%.
    2. Спектральный фризер (spectral freeze): wet 100%, fade-in ~350 мс, fade-out ~60 мс, re-trigger и freeze — вкл.
    3. Low-pass ~6 кГц.

    68. LFO Vibes — LFO-вайб #

    «Дышащий» фильтрованный звук с пульсирующим ревербом.

    1. EQ low-pass + реверб (decay ~1,2 сек).
    2. Один LFO управляет и частотой фильтра, и wet реверба (0–100%).
    3. Waveform: down, smoothing ~10%, rate = восьмая (зависит от BPM).
    4. Автоматизация depth «треугольником»: открыто → интенсивно → снова мягко.

    69. Movements — «движения» #

    Фоновый вайб, который «уходит и возвращается».

    1. Вокал → питч-шифтер −5 полутонов: автоматизация mix за ~8 тактов: вверх → выключить → вверх.
    2. Реверб decay ~4,5 сек: автоматизация wet той же формы (100% → 20% → обратно).
    3. Low-pass EQ в обратную сторону: от 1 кГц до открытого и обратно.

    70. Slowed & Reverb — замедленный с ревербом #

    Классический «slowed + reverb» стиль для целого трека.

    1. Растяни трек/секцию в 2 раза.
    2. Питч-шифтер: −12 полутонов, wet ~40% — характер и полнота.
    3. Реверб: decay ~3 сек, wet 60%.

    71. Evolving Tremelo — эволюционирующее тремоло #

    Тремоло, которое «морфится» со временем.

    1. Auto Pan в режиме tremolo: amount 100%, sync 1/16 + добавь attack.
    2. Включи invert shape и автоматизируй shape «треугольником»: 100% → −100% → 100%.

    Переходы и ризеры #

    72. Bass Drop — «открытие» на дропе #

    Дроп ощущается больше, когда бас «раскрывается».

    1. EQ band-pass 100–300 Гц на басах/секции перед дропом (звук «зажат»).
    2. Автоматизация: выключи EQ ровно в момент дропа — низы «открываются».

    73. Crush Transition — «краш»-переход #

    Драмы «раздавливаются» биткрашером на переходе.

    1. Вырежи секцию, где будет переход (драмы оставь).
    2. Сгруппируй все драмы (+ризеры/крэши) в одну группу.
    3. На группе: bitcrusher ~6 кГц, 16 bits, wet 100% + EQ high-pass ~150 Гц.
    4. Автоматизация: включи оба эффекта ровно на переходе.

    74. Intro Suspense — «напряжение» в интро #

    Интро, которое «втягивает» в трек.

    1. Автоматизация BPM: от четверти темпа трека до полного (например, 40 → 160).
    2. EQ low-pass на синте: от ~350 Гц до 22 кГц с лёгкой кривой.
    3. Pitch bend вниз (~квинта) той же кривой — ощущение «подъёма».

    75. Build Up — ризер из любого звука #

    Ризер, который «поёт» вместе с вокалом (или любым звуком).

    1. Вырежи маленький кусок вокала и скопируй его на 1/32 до дропа.
    2. Автоматизация питча: от 0 до +12 полутонов на всю фразу.
    3. Реверб decay ~11 сек: автоматизация времени от 0,25 сек до 11 сек и wet от 20% до 100%.
    4. Оставь хвост реверба открытым — пространство перед дропом.

    76. Shifty Transition — «сдвиг» на мастере #

    Скewed-переход на всём треке сразу.

    1. На мастере в точке перехода: EQ low-pass + high-pass; автоматизация частот так, чтобы полоса «раскрывалась» (low-pass от ~114 Гц до выключенного, high-pass от 2,5 кГц до открытого).
    2. Питч-шифтер wet 100%: автоматизация «безумной» формы: +12 → −24 → +12 → выкл.

    77. DJ — «диджейский» дроп #

    Фильтр + стаггер, как у диджея перед дропом.

    1. На мастере: EQ low-pass от 22 кГц до ~400 Гц и обратно вверх на дропе.
    2. Stutter (saw wave, инвертированная фаза): amount от 0% до 80% в той же точке; rate sync 1/16 три четверти перехода, затем ⅛ для удара.

    78. Rev Pitch — «реверс-питч» переход #

    Мелодичный skewed-переход из ресемплинга.

    1. Resample секцию в точке перехода на новую дорожку.
    2. Reverse → питч +12 полутонов.
    3. High-pass EQ: автоматизация от ~4 кГц до полностью открытого.

    79. Autobots — «автоботы» #

    Знаменитый переход «всё поднимается и открывается».

    1. На мастере в точке перехода: питч-шифтер wet 100%: автоматизация от −24 полутонов до 0.
    2. EQ high-pass: автоматизация от ~2 кГц до открытого (~10 Гц).
    3. Оба эффекта «раскрываются» одновременно — и готово.

    80. Sweepy — «пространственный» переход #

    Трек «растворяется в пространстве» перед дропом.

    1. На мастере за последние ~4 такта: реверб decay ~14 сек — автоматизация wet до ~60% и обратно.
    2. EQ high-pass: от 10 Гц до 1 кГц, держи секунду, затем сброс на дропе.

    81. EZ Risers — ризер из любого звука #

    Ризер буквально из чего угодно (даже лая собаки).

    1. Растяни звук + fade-in; warp Tones, grain size максимум.
    2. EQ low-pass: автоматизация от ~600 Гц до открытого.
    3. Реверб decay ~2,5 сек: автоматизация wet от 0% до ~50% — «хвост» ризера.

    82. Subby Transition — «субовый» переход #

    Переход на суб-ударах и «набухающей» полосе драм.

    1. Вырежи бас в секции перехода; сгруппируй драмы.
    2. На группе: low-pass от ~1,9 кГц до открытого + high-pass от выключенного (10 Гц) до 750 Гц — полоса «набухает».
    3. Добавь суб-дропы; один из них дублируй и reverse, чтобы они играли вразнобой.

    83. Cut Transition — «нарезка» #

    Классический переход с нарезкой кика и «аккордом» вокала.

    1. Дублируй секцию перехода дважды: первый дубликат питч +12, второй −12 — смешай с оригиналом (вокал превращается в трёхслойный аккорд).
    2. Сгруппируй драмы: возьми фрагмент кика и повтори его восьмыми на полтакта.
    3. Автоматизация mute группы on/off — чтобы не было хвостов реверба в «выключенных» местах.

    84. Rev Transition — «реверс»-переход #

    Кинематографичный переход из реверса следующей секции.

    1. Вырежи ~такт, где будет переход (всё).
    2. Возьми первый такт следующей секции (мелодии + бас), скопируй до неё и reverse все клипы; добавь fade-in'ы.
    3. Кинематографичный «бум»: один прямой + один реверс на вторую половину; оставь маленький хвост в конце.

    85. Cut & Move — «нарезка и движение» #

    Фанки-движение перед дропом: элементы входят по очереди.

    1. В такте перехода оставь только лид-синт (остальное вырежи).
    2. Приводи элементы в разное время: перкуссия чуть раньше → кик → бас.
    3. На лиде: high-pass от ~600 Гц до открытого + панорама справа налево на каждом фрагменте — стерео-«воздух».

    86. Tran Flange — «скрип двери» #

    Переход, похожий на скрипящую открывающуюся дверь.

    1. В двух тактах перехода: удали драмы, оставь мелодии (+ризеры); сгруппируй.
    2. Автоматизация high-pass от ~516 Гц до открытого с кривой.
    3. Flanger на группе: rate 2, amount 0, feedback 75%, wet ~43%; включай только на переходе и автоматизируй время (например, от ~20 мс до ~100 мс).

    87. Slow Down — «замедление» секции #

    «Замедленная» версия своего же трека — идеально для аутро.

    1. Resample секцию трека на новую дорожку.
    2. Slice в MIDI (четверти) → сыграй свой паттерн.
    3. Питч −12 полутонов + реверб decay ~2,3 сек, wet ~13,5%.
    4. Смешай с оригиналом.

    88. One At A Time — «по одному» #

    Ритмичная «обработка» всего трека эффектами по очереди.

    1. На мастере поставь четыре эффекта (например: overdrive, реверб, питч-шифтер, EQ).
    2. Автоматизация: каждый эффект включается/выключается по одному на каждую четверть.
    3. Отлично работает и как переход, и как саунд-дизайн.

    Сайдчейн, гейты и вокодеры #

    89. Get Gated — «гейт» от чопов #

    Мелодии играют только в момент ударов чопов.

    1. Сгруппируй все мелодии в одну группу.
    2. Отдельная дорожка (вне группы) с вокальными чопами (или любым нарезанным звуком).
    3. Gate на группе мелодий: сайдчейн от дорожки чопов.
    4. Threshold так, чтобы мелодии звучали только когда играет чоп.

    90. Bouncy Vocoder — «прыгучий» вокодер из перкуссии #

    «Поющий» перкуссионный луп через вокодер.

    1. Перкуссионный луп → slice в MIDI (четверти).
    2. Сгенерируй случайный паттерн (Ableton: Seed → Generate) или сыграй вручную.
    3. Вокодер с внешним carrier от синта, играющего аккорд (синт замкнут в миксе — влияет только на тембр).
    4. Подстрой release и formant (~−4).
    5. OTT ~30–35% для финального «буста».

    91. Voice Gate — гейт от голоса #

    Пэд, который играет, когда ты говоришь в микрофон (live-эффект).

    1. Пэд на дорожке + gate-плагин.
    2. Сайдчейн гейта — с дорожки микрофона (твой голос).
    3. Threshold: пэд звучит только пока ты говоришь/поёшь.

    Сэмплирование и ресемплинг #

    92. Chops — «новая мелодия» из своего трека #

    Свой трек становится играбельным инструментом.

    1. Resample/freeze луп-секцию (например, такт) на аудио-дорожку.
    2. Slice в новую MIDI-дорожку (half note).
    3. Питч −12 полутонов, attack ~120 мс — «парящий» вайб.
    4. Играй новые мелодии на клавиатуре из звуков своего же трека.

    93. Foley Fun — аккорды из фoley-звуков #

    Красивые «природные» пэды из бытовых звуков.

    1. Частоты соответствуют нотам: например, C = 261 / 523 / 1047 Гц, F ≈ 1396–1400 Гц.
    2. Возьми фoley-звук и сдвинь его так, чтобы резонансы попадали в частоты нот (низ/середина/верх).
    3. Загрузи в самплер (ключевая нота — middle C) → band-pass EQ 200–900 Гц.
    4. Играй аккорды — получается «река с птицами» из одного звука.

    94. Lead Bounce — «прыгучий» лид из one-shot #

    Ритмичный лид-слой из одиночного сэмпла (даже лая собаки).

    1. Очень короткий slap-делэй (klzxh:0369), feedback 95%, wet 50% — почти бесконечное эхо.
    2. Бесплатный LFO/tremolo-плагин — для «отскока».
    3. OTT ~60%.
    4. High-pass ~190 Гц; смешай в трек.

    95. Oneshot Bonanza — «конфетка» из one-shot #

    Ear candy: маленький перкусивный элемент для фона микса.

    1. Короткий one-shot (вокал/перкуссия) → сильная сатурация (drive 6, wet максимум, агрессивный режим).
    2. Реверб: decay ~8 сек, wet 100%.
    3. Band-pass EQ 200 Гц – 2,5 кГц — отодвигает назад.

    96. Re-Resampled — «пересэмплинг» хаоса #

    Триповая ломка секции трека на микрофрагменты.

    1. Resample часть трека на новую дорожку.
    2. Пройдись по всему клипу: реверси куски, дублируй, меняй питч, зумни и вырезай микро-фрагменты — «ломай» звук.
    3. Затем деактивируй/вырежи части так, чтобы две версии чередовались — триповый перепад.

    97. Granulator 3 — гранулярная автоматизация #

    Триповое «зерно», прыгающее по сэмплу.

    1. Сэмпл (например, пэд) в гранулярный плагин (Granulator 3).
    2. Автоматизация position каждые ~такт — в разные точки сэмпла.
    3. В тех же местах автоматизация grain size (в мс; например, ~3,5 мс = шестнадцатая на 174 BPM — конвертируй онлайн).

    98. Ableton EZ Stuts — стаггеры в Ableton за минуту #

    Стаггер прямо из настроек клипа.

    1. Аудио-клип: warp Beats.
    2. В редакторе задай Preserve на нужную скорость (например, 1/16) и смени режим по умолчанию.
    3. Тяни transient-envelope вниз — клип начинает стаггерить; меняй скорость для разных темпов.

    99. EZ Chops — случайные чопы #

    Случайная чоп-последовательность из вокала одним кликом.

    1. Вокал → slice в новую MIDI-дорожку (четверти).
    2. Удали все ноты.
    3. Ableton: Seed → Generate — случайный паттерн чопов; жми Generate снова для новых вариаций.

    100. EZ Chops+ — «обработанные» чопы #

    Полированная версия фишки 99.

    1. Возьми результат EZ Chops и добавь цепочку:
    2. Питч-шифтер +12 полутонов, wet 50%;
    3. OTT ~64%;
    4. EQ high-pass ~200 Гц;
    5. Реверб decay ~4,3 сек, wet 40%.

    Как тренироваться

    Не пытайся выучить все 100 сразу. Выбери одну категорию (например, «Переходы и ризеры»), сделай по одной фишке в каждом своём следующем треке — через месяц они станут рефлексами. А потом соберите свой набор из 20 любимых приёмов: это и есть ваш продакшн-подпись.
