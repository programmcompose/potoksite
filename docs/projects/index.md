## Как устроена система

**Урок → маленькое действие в DAW → накопление → проект → сдача → следующий этап.**

Проект не заменяет статьи. Он отвечает на вопрос: **«Что я должен реально сделать после изучения этого этапа?»**

<div class="potok-project-index-note">
<strong>Важно:</strong> отметки чеклиста хранятся только на текущем устройстве и в текущем браузере.
Если ученик очистит данные сайта или сменит устройство, отметки исчезнут. Для первой версии это сознательная замена личному кабинету.
</div>

## Принцип

На каждом этапе есть один главный результат. Не нужно сдавать каждую мелочь преподавателю: мелкие действия нужны для практики, а проект показывает, что ученик смог собрать всё вместе.

### Для преподавателя

Проектная страница не требует отдельной инфраструктуры. Ты можешь:

1. менять задания прямо в Markdown;
2. отправлять ученика на существующие уроки;
3. принимать финальный файл в текущем Telegram;
4. позже, если появится личный кабинет, заменить только слой хранения прогресса.

## Технически

Система состоит из:

- `projects.css` — оформление;
- `projects.js` — сохранение чеклистов в `localStorage`;
- `projects/*.md` — сами проекты;
- двух изменений в `mkdocs.yml` — подключение CSS/JS и раздел навигации.
