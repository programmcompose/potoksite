# <i data-lucide="book-marked" class="page-icon"></i> Справочники

Быстрые справочные материалы курса: базы, которые вы будете открывать во время работы в DAW — не для чтения подряд, а «под рукой».

## Что здесь

| Справочник | Для чего |
|------------|----------|
| [База референс-треков](referensy.md) | Проверенные треки по жанрам курса: BPM, тональность, что именно слушать. Ориентир для сведения и анализа аранжировок. |
| [Библиотека пресетов](presety.md) | Пресеты курсовых плагинов с аудио-демо: что делает каждый пресет и когда его применять. |

!!! tip "Как пользоваться"
    Справочники — это не этапы курса, а инструменты рядом с ними.
    На этапе 2 (сведение) держите открытой базу референсов, на этапах
    с плагинами — библиотеку пресетов.
