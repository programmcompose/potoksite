# <i data-lucide="disc-3" class="page-icon"></i> База референс-треков

Референсный трек — профессиональный ориентир, с которым вы сравниваете свой: громкость, спектр, баланс, структуру. Методика работы с референсами разобрана в [Этапе 2](../etap2/references.md) и [Этапе 4](../etap4/rabota-s-referensami.md). Здесь — сама база треков по жанрам курса.

> **Начальный список.** BPM и тональности взяты из открытых источников — проверяйте своими инструментами (это отдельная полезная практика). Свои референсы с потоков добавляем сюда же.

## Как выбирать референс

1. **Жанр и темп** как у вашего трека — иначе сравнивать нечего
2. **Громкость** конкурентная: трек должен звучать «как из того же магазина»
3. **Структура** понятная: слышны вступление, куплет, припев, бридж
4. Один референс на задачу: для баса — трек с жирным басом, для вокала — трек с чистым вокалом
