1 Осцилляторы

Сырой тембр. Пила — все гармоники (бас, лид). Квадрат — полые. Треугольник — мягко. Синус — чистый тон.

2 Фильтр Moog

24 дБ/окт лестница. Cutoff срезает верха, Resonance ставит пик на срезе — тот самый «квак».

3 Огибающая

Жизнь ноты: Attack — появление, Decay — спад к Sustain, Release — хвост после клавиши.
