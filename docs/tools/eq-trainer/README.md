# EQ-тренажёр — улучшенная версия

Готовый к вставке на сайт самодостаточный `index.html`.

## Что улучшено относительно оригинала

1. **Горячие клавиши**
   - `Z` / `X` — ДО / ПОСЛЕ
   - `Пробел` — play/pause
   - `A` — автопереключение A/B
   - `Enter` — проверить / новый раунд
   - `1–6` — выбор полосы

2. **Обратная связь после ответа**
   - Две кривые EQ на canvas: зелёная = правильно, оранжевая = ваш ответ
   - Кнопки «Послушать ошибку» и «Правильный вариант»
   - Чёткий текст: что было правильно и что выбрали вы

3. **Карта навыков (localStorage)**
   - Статистика по зонам: Низ / Середина / Верх
   - Сохраняется между сессиями (`eq-trainer-v2`)

4. **UX**
   - Зацикливание короткого фрагмента (~4.5 с)
   - Статус «сейчас играет ДО/ПОСЛЕ» с цветной точкой
   - Toast-уведомления
   - Тема светлая/тёмная (как в оригинале)

5. **Встроенные источники** (синтез Web Audio, без внешних файлов)
   - Барабаны, Микс, Пианино, Розовый шум
   - + загрузка своего трека (MP3/WAV/OGG)

## Как поставить на сайт

Скопируйте папку `eq-trainer/` в `tools/` (или куда нужно) и замените/добавьте ссылку.

Файл один — `index.html`. Никаких зависимостей кроме Lucide icons (CDN).

## Для нейросети / дальнейшей доработки

В конце скрипта есть блок TODO:

```
// TODO для нейросети / дальнейшей доработки:
// 1. Режим «Исправь EQ»: дать уже изменённый звук + параметрический EQ (gain + Q + freq)
// 2. Адаптивная сложность: чаще выдавать зоны, где zoneStats.ok/total низкий
// 3. Мультиполосные изменения (2 полосы сразу) на очень сложном уровне
// 4. Загрузка нескольких пользовательских файлов + плейлист
// 5. Экспорт статистики / шаринг результата в Telegram
// 6. Визуальный спектр (AnalyserNode) в реальном времени рядом с кривой EQ
```

Структура кода:
- `LEVELS` — все уровни сложности
- `state` — единое состояние
- `ensureAudio` / `startPlayback` / `armFilter` — аудио-движок
- `synthesize*` / `createPinkNoise` — генерация звука
- `drawEQCurve` — визуализация
- `saveStats` / `loadStats` — localStorage

Можно безопасно расширять, не ломая текущую логику.
