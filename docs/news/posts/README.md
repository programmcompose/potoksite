# Как добавить пост в «Новости Потока»

Этот файл — документация для владельца/ассистента, на сайт не публикуется.

## Способ 1: сам файл

Создайте `.md`-файл в этой папке (`docs/news/posts/`) с любым именем (латиницей, через дефис):

```markdown
---
title: "Название поста"
date: 2026-10-15          # дата публикации — пост появится в фиде в этот день сам
type: этап                # этап | ивент | инфо (без type будет «инфо»)
image: assets/news/cover.png   # опционально, путь от docs/; без картинки — заглушка
teaser: "Короткое описание для фида (1-2 предложения)"
---

Полный текст поста. Обычный markdown: списки, ссылки, изображения, цитаты.
```

Затем `git add . && git commit -m "новость" && git push` — после деплоя пост будет на сайте.

**Важно:** если `date` в будущем — пост не исчезнет, а будет ждать в блоке «Впереди» и переедет в фид сам в назначенный день (без повторной пересборки).

## Способ 2: голосом/текстом ассистенту

Просто скажите: «добавь новость: <что>, дата <когда>, тип <этап/ивент/инфо>» — ассистент создаст файл, картинку (если нужно) и закоммитит.

## Правила

- `date` — строго `YYYY-MM-DD`. Граница публикации — 00:00 МСК.
- `type`: `этап` (выход этапа курса), `ивент` (сессия/батл/стрим), `инфо` (важное объявление).
- Обложки кладите в `docs/assets/news/`. Рекомендуемый размер — 900×500.
- Файлы без `title` или с кривой датой пропускаются при сборке с warning — проверьте вывод `mkdocs build`.
- Удалить пост = удалить файл и закоммитить.
