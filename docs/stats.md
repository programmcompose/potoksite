# <i data-lucide="bar-chart-3" class="heading-icon"></i> Статистика и бейджи

Отслеживайте свой прогресс, уровень и активность в курсе «18 ПОТОК», а также собирайте коллекцию бейджей.

## Система уровней

Каждое действие приносит **XP (опыт)**:

| Действие | XP |
|----------|-----|
| Просмотр страницы | +5 |
| Начало сессии | +3 |
| Пройденный урок | +25 |
| Получение бейджа | +50 |

Повышение уровня **не даёт дополнительного XP** — опыт начисляется только за действия из таблицы выше.

Чем выше уровень, тем больше XP нужно для следующего: требование растёт примерно на **20% с каждым уровнем**. Максимум — **50 уровней**.

## Бейджи

Добивайтесь целей в обучении и получайте бейджи! Каждый бейдж даёт **+50 XP** и приближает вас к следующему уровню.

### Как получить бейджи

Бейджи начисляются **автоматически** при выполнении условий:

| Редкость | Цвет | Описание |
|----------|------|----------|
| `Обычный` | Серый | Доступные с первых шагов |
| `Необычный` | Зелёный | Требуют регулярного обучения |
| `Редкий` | Синий | Для постоянных учеников |
| `Эпический` | Фиолетовый | Для преданных студентов |
| `Легендарный` | Оранжевый | Вершина мастерства |

## Управление данными

### Экспорт
Сохраните прогресс в JSON-файл для резервной копии или переноса на другое устройство.

### Импорт
Загрузите ранее экспортированный файл для восстановления прогресса.

### Сброс
Полный сброс всех данных геймификации. **Внимание:** действие необратимо!

!!! warning "Конфиденциальность"
    Данные профиля хранятся под вашим Telegram ID: в LocalStorage браузера, а при открытии через Telegram Mini App — дополнительно в CloudStorage Telegram. Аудио и файлы треков не сохраняются, только метаданные и ссылки.
